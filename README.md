# jesusfetch
### a Christianity based systemfetch written in Python!

## Supported systems:
+ Windows🪟
+ Linux🐧
+ MacOS🍎

## How do jesusfetch.py ​​and jesusfetchGPU.py be different from each other?
+ jesusfetchGPU.py: I replaced the “Uptime” section with information about the GPU and its usage % !
+ jesusfetch.py its the original version.

### What does this tool do?
This tool prints your system info locally in your Terminal in a Christian way!

It shows your:
+ OS
+ Host
+ Kernel
+ CPU & its usage %
+ Memory
+ Disk
+ Uptime
+ GPU & its usage % (only available on jesusfetchGPU.py)

## Required:
+ Python🐍
+ link: https://www.python.org/
+ psutil
+ link: https://pypi.org/project/psutil/
